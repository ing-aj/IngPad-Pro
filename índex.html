        📐 Plantillas de Ingeniería y Programación
        
      

      

        

          Selecciona una plantilla para abrirla en una pestaña nueva lista para editar o exportar en tu iPhone:
        

        

          

            
.lsp — AutoLISP Capas y Polilínea

            
Comando C:EJEMPLO con manejo de errores, captura de puntos, creación de capa y dibujo en AutoCAD.

          

          

            
.lsp — Exportar Coordenadas a CSV

            
Rutina AutoLISP que selecciona vértices de polilíneas (LWPOLYLINE) y los guarda en un archivo CSV.

          

          

            
.scr — Script de AutoCAD por Lotes

            
Script automático para configurar unidades, crear capas e insertar polilíneas por coordenadas X,Y,Z.

          

          

            
.gcode — Fresado CNC 3 Ejes

            
Programa G-Code estándar (G21, G90, G54, M03, compensación y ciclo de fresado de contorno).

          

          

            
.csv — Puntos Topográficos COGO

            
Formato P,N,E,Z,D (Punto, Norte, Este, Elevación, Descripción) para Civil 3D / Topografía.

          

          

            
.py — Cálculo Estructural / Hidráulico

            
Script en Python con cálculo de deflexión de viga e iteración de Manning para canales abiertos.

          

          

            
.m — Script MATLAB / Octave

            
Análisis matricial de rigidez y respuesta dinámica de un sistema masa-resorte-amortiguador.

          

          

            
.dxf — Archivo DXF ASCII Mínimo

            
Estructura pura de código DXF con sección ENTITIES para generar geometría CAD desde texto.

          

        

      

    

  


  
  

    

      

        ⚙️ Herramientas de Ingeniería y Código
        
      

      

        
        

          
1. Auditor de Paréntesis y Sintaxis AutoLISP (.lsp)

          

            Analiza el archivo actual ignorando comentarios (;) y cadenas de texto ("...") para detectar paréntesis sin cerrar.
          

          

            
            
          

          

        


        
        

          
2. Convertidor de Coordenadas (CSV → Script AutoCAD .scr)

          

            Convierte las líneas X,Y,Z o P,N,E,Z,D del archivo actual en un script .scr de AutoCAD con comandos _3DPOLY o _POINT.
          

          

            
            
            
          

          

        


        
        

          
3. Numerador de Bloques CNC G-Code (N10, N20...)

          

            Agrega o limpia numeración secuencial de líneas para controles Fanuc, Haas y Siemens.

        🐙 Cómo alojar en GitHub y usar como App en iPhone
        
      

      

        

          
Paso 1: Subir a GitHub Pages (100% Gratis)

          
    
            
  1. Crea un repositorio nuevo en github.com (por ejemplo: ingepad-pro).
    2. 
            
  2. Sube este archivo con el nombre exacto index.html.
    3. 
            
  3. En tu repositorio, entra a Settings → Pages y en Branch elige main y guarda.
    4. 
            
  4. En 1 minuto tu app estará disponible en https://tu-usuario.github.io/ingepad-pro/.
    5. 
          

          

            
          

        


        

          
Paso 2: Instalar en la Pantalla de Inicio del iPhone

          
    
            
  1. Abre tu enlace de GitHub Pages en Safari desde tu iPhone.
    2. 
            
  2. Toca el botón Compartir (el cuadro con la flecha hacia arriba en la barra inferior).
    3. 
            
  3. Selecciona "Agregar a pantalla de inicio".
    4. 
            
  4. ¡Listo! Se abrirá a pantalla completa como una aplicación nativa sin barras de Safari y funcionará incluso sin conexión a internet.
    5. 
          

        


        

          
Paso 3: Guardar archivos .LSP en la app Archivos de iOS

          

            En tu iPhone puedes tocar "📲 Compartir iOS" → "Guardar en Archivos" o "💾 Guardar" para almacenar tus rutinas .lsp, .scr, .gcode o .py directamente en iCloud Drive, En mi iPhone, o enviarlas por AirDrop/Correo a tu PC con Windows.
